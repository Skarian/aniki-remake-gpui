# Launch and audio QA — 2026-11-09

Local Windows desktop tests used the installed launcher, the existing game library,
and virtual Xbox or DualShock 4 input. These are brief startup/gameplay/return checks,
not complete game compatibility certification. Apollo remote-client delivery was
not measured during this run.

all player/controller setting lines were unchanged. No controller profile was
reverted, and no driver or OS update was installed. Normal game save behavior can
occur when continuing and moving in an existing save.

## Audio

The legacy music path produced Windows MCI errors and no usable output. Music now
uses FFmpeg and a bounded SDL PCM queue, loops, and closes on game launch or loss
of focus. Returning to the launcher resumes it. Windows mixer settings and source
tracks were not modified. The default linear gain is 0.5.

Measurements use 12-second speaker-loopback samples, never microphone input.
Different menu segments and musical dynamics mean these are useful calibration
samples, not exact whole-game loudness measurements. Quiet introductions in the
existing Zelda and Octopath music are retained rather than aggressively boosted.

At gain 0.5, the NBA launcher track measured -14.51 LUFS; the game's menu sample
measured -15.03 LUFS and its exhibition introduction -14.44 LUFS. This is a close
match for those segments. Sample peak was -0.13 dBFS and estimated true peak
+0.04 dBTP, so this endpoint has little peak headroom; the loudness measurement
does not establish distortion-free playback on every output device.

Other measured game samples ranged from -12.08 LUFS (Octopath title) to -30.28
LUFS (Pokemon loading/ambient). Silent Zelda and Smash startup recordings were
excluded from calibration; Smash's match introduction measured -18.79 LUFS.
God of War and Helldivers did not reach a suitable gameplay/audio test state.

Final automated regression results are pending.

## Limits

Foreground ownership and window stacking were checked, but frame-by-frame absence
of taskbar exposure is not proven. The readiness heuristic approximates the local
Aniki helper and does not duplicate every splash-window filter. See
[Playnite alignment](playnite-alignment.md).
